# 2. Arquitetura do Sistema

A aplicação foi estruturada em duas camadas principais:

- frontend: interface responsiva desenvolvida com React e Vite;
- backend: API REST desenvolvida com Node.js e Express.

## Componentes principais

- autenticação com JWT;
- rotas protegidas para gestão de usuários e estagios;
- banco de dados PostgreSQL;
- upload de documentos via multer;
- comunicação entre frontend e backend via HTTP.

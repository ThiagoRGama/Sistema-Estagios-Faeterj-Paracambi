# 3. Implantação e Execução

## Passos para execução

1. Instalar as dependências do backend.
2. Configurar o arquivo .env com a URL do banco PostgreSQL.
3. Executar as migrações e o seed inicial.
4. Iniciar o backend e o frontend.

## Observações

O projeto pode ser executado localmente para fins acadêmicos e também adaptado para ambientes de homologação e produção.
